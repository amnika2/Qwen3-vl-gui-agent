本次修复：

- 字段别名进入统一评分流程，例如 `Page Title → Title`、`SideNote → Side note`。别名合并后出现重复字段会判为格式错误，避免重复声明覆盖错值。
- 已核验的替代截图进入训练评分。重开的截图冒充原始基准，仍按无效引用处理。
- 三个经过原图确认的额外字段可以接受；它们无需每次输出，也不会增加部分正确分。额外字段的值、意图和判断标志仍逐项比较。
- 保持原值时，`unchanged` 与已知原始值等价；不同的字面值继续报错。
- 已确认的独立错误可以得到固定负分 `-1`，即使另有未知字段。字面值错误需要该字段自己的截图引用已经核验；未知截图上的不同读数继续保留待确认。
- 截断判断接入 TRL 0.27.2 已提供的 `completion_ids`，与其结束 token 判据一致。训练与复评共用同一个打分函数，截断回答保持 `reward=null`，整组 G4 的任务奖励置零。

通用字段别名按应用场景限定作用域。替代截图、无效引用、颜色限定别名和额外字段按具体来源运行及样本 ID 绑定，入库时核验每步截图 SHA256，后续候选评分复用结果。当前规则绑定 51 个训练样本、185 步原图。规则标定只使用训练数据。
