# 独立判据修正

在 `runs/20261106T165706Z-fb7523be/private/oracle.json` 中，首次保存后的重开观察（step 5）为手机号空值，后续模型未保存的重新输入又覆盖了实际值。旧判据因重复读取编辑框而把最后编辑值当成持久化值。

修正：每次真实提交重置观察状态；只锁定这次提交后首次可见、同一业务对象的有效重开结果。后续未提交的输入不覆盖这份证据。新的真实提交才开始下一次观察。事件同时保存对象一致性、步骤及截图。

已加入两个回归测试：服务人员手机号与用户昵称，均验证“重开后看到旧值 → 再次输入但不保存”仍判为原始保存结果。原始模型报告不改写。

受影响的第二轮完整排程保留在 `evaluation-075e36a6`、`evaluation-e2204e99`，作为判据诊断数据，不计作修正后主分析。每个原计划格子的状态仍单列。

控制器、动作执行、模型提示词、预算和公共用例均与第二轮逐字节核对保持不变，证据见 `docs/controller-freeze-verification.json`。第三轮仅使用修正后的独立判据。
